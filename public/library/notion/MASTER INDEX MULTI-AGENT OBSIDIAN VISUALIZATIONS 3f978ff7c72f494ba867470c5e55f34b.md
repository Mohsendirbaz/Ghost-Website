## 🚀 QUICK START GUIDE

### Beginner Path (30 minutes)

1. **Install Obsidian** (if not already)
2. **Create new vault** or use existing
3. **Install Dataview plugin:**
    - Settings → Community Plugins → Browse
    - Search “Dataview” → Install → Enable
4. **Copy essential files:**
    - `MultiAgent_Coordination_Canvas.canvas`
    - `MultiAgent_Mermaid_Diagrams.md`
    - One template file
5. **Open Canvas:**
    - Right-click canvas file → Open in Canvas
    - Explore the visualization
6. **View diagrams:**
    - Open Mermaid diagrams file
    - Switch to Reading Mode (Ctrl/Cmd + E)
    **Result:** Visual understanding of multi-agent architecture

---

### Intermediate Path (60 minutes)

1. **Complete Beginner Path**
2. **Set up folder structure:**
    
    ```
    YourVault/
    ├── agents/
    ├── tasks/
    ├── workflows/
    ├── chapters/
    ├── templates/
    └── visualizations/
    ```
    
3. **Copy templates to** `templates/` folder
4. **Create dashboard:**
    - New note: `Multi-Agent Dashboard.md`
    - Paste dashboard code from templates file
5. **Configure Graph View:**
    - Open Graph View (Ctrl/Cmd + G)
    - Apply agent-centric configuration
6. **Install recommended plugins:**
    - Dataview ✅
    - Kanban
    - Calendar
    **Result:** Functional tracking system

---

### Advanced Path (2+ hours)

1. **Complete Intermediate Path**
2. **Apply CSS snippets:**
    - Create `.obsidian/snippets/` folder
    - Copy CSS code to snippet files
    - Enable in Settings → Appearance
3. **Set up advanced queries:**
    - Create analysis notes
    - Use JavaScript Dataview queries
4. **Configure additional plugins:**
    - Tasks plugin for advanced task management
    - Templater for dynamic templates
    - DB Folder for database views
5. **Create custom workflows:**
    - Design workflow templates
    - Set up automation
6. **Customize for your project:**
    - Adapt templates
    - Modify queries
    - Adjust visualizations
    **Result:** Production-ready multi-agent management system

## 🔧 TROUBLESHOOTING

### Problem: Mermaid diagrams don’t render

**Solution:**

- Ensure you’re in **Reading Mode** (not Edit mode)
- Settings → Core Plugins → Enable “Mermaid”
- Update Obsidian to latest version

---

### Problem: Dataview queries show errors

**Solution:**

- Install Dataview plugin
- Check field names match your notes
- Enable Dataview in Settings

---

### Problem: Canvas files won’t open

**Solution:**

- Update Obsidian to v1.0.0+ (Canvas added in v1.0)
- Right-click file → Open in Canvas
- Move file to vault root if in subfolder

---

### Problem: CSS snippets don’t work

**Solution:**

- Check file location: `.obsidian/snippets/`
- File must end in `.css`
- Toggle snippet on in Settings → Appearance
- Reload Obsidian (Ctrl/Cmd + R)

---

### Problem: Graph view looks cluttered

**Solution:**

- Use filters to hide notes
- Apply color groups configuration
- Increase repel strength
- Hide attachments and unresolved links
