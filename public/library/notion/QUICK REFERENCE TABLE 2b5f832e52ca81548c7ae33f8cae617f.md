## Usage Examples

### For Quick Subsection Planning:

1. Identify chapter (e.g., Chapter 15)
2. Note target % (4.1%) and words (533)
3. Check tone target (A:20 T:65 G:5 P:10)
4. Subdivide to subsections (5 items shown above)
5. Write with tone awareness

### For Rebalancing During Revision:

1. Measure actual word counts per chapter
2. Calculate actual %: (Words / 13000) × 100
3. Compare to target (column 2)
4. If deviation > 1%: redistribute content
5. Maintain Part-level totals

### For Tone Verification:

1. Sample 3-5 paragraphs per subsection
2. Code each sentence: A, T, G, or P
3. Calculate %: (Count_A / Total) × 100, etc.
4. Compare to target (column 4)
5. If deviation > 5%: revise phrasing
