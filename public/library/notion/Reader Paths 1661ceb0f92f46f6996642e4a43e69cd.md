## Project Description

📘 PROSECUTING INEQUITY: Book Structure & Reader Paths

400-500 page academic/policy book on climate investment, social decay, and equitable decarbonization. This project provides a comprehensive navigation map for seven distinct reader types: policy makers, academics, technical specialists, graduate students, general audience, rural stakeholders, and religious leaders.

🎯 PURPOSE OF THIS PROJECT MAP:

This project structure serves two critical functions:

1. READER NAVIGATION: Each chapter/section is tagged with reader-specific relevance markers (CRITICAL/IMPORTANT/OPTIONAL/SKIP) to help different audiences find their optimal reading path through the 28 chapters and appendices.

2. AUTHORIAL FINE-TUNING: This map enables the author to refine specific segments, sections, or chapters based on the intended audience path. When revising, the author can:
   - Prioritize depth/detail in chapters marked CRITICAL for target audiences
   - Adjust technical complexity based on primary vs. secondary reader tags
   - Add cross-references between chapters along common reading paths
   - Ensure jargon/terminology aligns with reader expertise levels
   - Balance page count by identifying chapters with multiple CRITICAL tags (requiring more development) vs. chapters with mostly OPTIONAL tags (candidates for condensing)

⚠️ COMPLIANCE INSTRUCTION:
Before working on any chapter or providing feedback on specific sections, ALL users (collaborators, editors, reviewers) MUST first read the complete project description and consult the 📚 Reading Path Guide and 📊 Quick Reference Matrix tasks to understand:
- Which reader types prioritize this chapter
- How this chapter connects to other chapters in key reading paths
- The intended depth and complexity level for the content
- Cross-path dependencies that require careful handling

This ensures all revisions maintain structural integrity and serve the book's multi-audience design.
