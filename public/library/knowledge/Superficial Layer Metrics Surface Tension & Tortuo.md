# Superficial Layer Metrics: Surface Tension & Tortuosity

## Overview

This page documents **superficial overlay metrics** that broker the **discrete-continuous dilemma** through physics-based interpretable representations. The term "superficial" follows topological convention: boundary measures (∂A) rather than interior/volume measures (int(A))—carrying no pejorative implication.

**Core Motivation**: Text is fundamentally discrete (words, sentences, paragraphs) but linguistic phenomena (coherence, tone, quality) are continuous fields. The measure-theoretic framework captures this rigor via (Ω, ℱₙ, μ_w, {μ_j}), but visualization must **render continuous measures perceptually interpretable** by anchoring them to discrete visual structures.

**Design Philosophy**: Superficial layer metrics exploit **boundary phenomena** because boundaries naturally mediate the discrete-continuous gap—they are where discrete structure (sentence i | sentence i+1) meets continuous field variation (∇c, ∂γ/∂s).

## The Discrete-Continuous Dilemma in Linguistic Quality

### Problem Statement

**Discrete Reality**:

- Text tokenizes into countable units: {w₁, w₂, ..., wₙ}
- Structure hierarchizes: sentence ⊂ paragraph ⊂ section ⊂ chapter
- User perception operates on discrete attention quanta

**Continuous Phenomena**:

- Coherence flows smoothly across boundaries
- Tonal composition c ∈ Δₘ₋₁ varies continuously
- Quality metrics Q : ℱ → [0,1] are real-valued fields

**Mathematical Resolution** (Analytics Core):

- σ-algebra ℱₙ generated by measurable sets A ∈ 2^Ω
- Measures μ : ℱ → ℝ₊ provide continuous valuations
- Radon-Nikodym derivatives dμ_j/dμ_w yield continuous compositions

**Perceptual Gap**:

- Humans cannot directly perceive measure-theoretic structures
- Conditional expectations 𝔼[c | ℱ] are cognitively opaque
- σ-algebra refinements ℱ₀ ⊃ ℱ₁ ⊃ ... ⊃ ℱₙ lack visual anchors

### Why Visualization Brokers This Dilemma

**Unique Dual Representation**:

Visualization can **simultaneously** present:

1. **Discrete Anchors**: Entity grid cells, sentence boundaries, paragraph divisions
2. **Continuous Fields**: Color gradients, border thickness, spatial position

This duality is impossible in:

- Pure symbolic representation (LaTeX formulae show continuous math, lose discrete structure)
- Pure textual representation (shows discrete words, loses continuous field variation)
- Pure numerical representation (tables are discrete, require interpolation to visualize continuity)

**Example: Entity Grid Heatmap**

| Representation | Discrete Elements | Continuous Fields |
| --- | --- | --- |
| **Text alone** | Words, sentences | ✗ No field visualization |
| **Equations alone** | ✗ No structural anchors | ∇c, ∂Q/∂c shown symbolically |
| **Heatmap** | Grid cells (sentence × entity) | Color gradient (coherence field) |

The heatmap makes the continuous coherence field **interpretable** by discretizing it onto a perceptual grid while preserving smooth color variation.

## Physics-Based Formulation as Interpretability Engine

### Why Physics Analogs Increase Interpretability

**Dimensional Reasoning**:

- Physics grounds abstract quantities in units: [Force] = kg·m/s²
- Linguistic analogs inherit dimensional structure: [γ_sem] = ∂(tonal energy)/∂(sentence boundary)
- Units enable **scaling intuition**: "Is γ = 0.5 large?" → "Compared to what reference state?"

**Conservation Laws**:

- Physics: ∑ c^(j) = 1 (probability conservation)
- Semantics: ∑ μ_j = μ_w (tone measures sum to total word measure)
- Violation of conservation → immediate visual flag (impossible color in simplex projection)

**Field Theory Intuition**:

- Physics: Electric field E = -∇φ (gradient of potential)
- Semantics: Surface tension γ_sem = ||∇c|| (gradient of tonal composition)
- Humans have evolved intuition for gradients (slopes, brightness changes, temperature variations)

**Boundary Value Problems**:

- Physics: ∫_∂A σ·n dS = ∫_A ∇·σ dV (divergence theorem)
- Semantics: Boundary discontinuity (γ_sem) ↔ Interior shear (τ^vert via Stokes)
- Users see boundary phenomena (borders) but can drill down to bulk properties (interior analysis)

### Case Study: Why Surface Tension Works

**Physical Surface Tension** (γ in N/m):

- Minimizing interfacial energy → water droplets become spherical
- Directly observable: soap bubbles, capillary rise, insect water-walking
- **Interpretable** because humans have tactile + visual experience with interfaces

**Semantic Surface Tension** (γ_sem):

$$
γ_{\text{sem}}(i, i+1) = \sum_{j=1}^{m} |c_i^{(j)} - c_{i+1}^{(j)}| \cdot w_j
$$

- Measures "energy cost" of tonal interface between sentences
- γ_sem = 0 → smooth flow (minimal energy, like water in equilibrium)
- γ_sem >> 1 → abrupt discontinuity (high energy interface, like oil-water boundary)
- **Interpretable** because color-coded borders invoke physical intuition: thick red border = "high tension" = "hard to flow through"

**Why Not Just Show Raw c_i, c_{i+1}?**

Showing raw composition vectors:

- c_i = [0.3, 0.5, 0.1, 0.1] (Academic, Technical, General, Policy)
- c_{i+1} = [0.1, 0.2, 0.6, 0.1]

Requires user to:

1. Compute ||c_i - c_{i+1}||₁ = |0.3-0.1| + |0.5-0.2| + |0.1-0.6| + |0.1-0.1| = 1.0
2. Interpret 1.0 in context of max possible distance (2.0 for disjoint compositions)
3. Map 1.0 → "This is a large discontinuity"

Showing γ_sem as colored border:

- User sees **red thick line** → immediate perception: "abrupt transition here"
- No calculation required
- Physical intuition carries interpretation

## Measure Group Selection for Superficial Layer

### Principle: Boundary Measures Mediate Discrete-Continuous Structure

**Topological Distinction**:

For measurable set A ∈ ℱ:

- **Interior** int(A): Pure continuous (requires integration, ∫_A f dμ)
- **Boundary** ∂A: Discrete-continuous interface (point evaluation limits from both sides)

**Why Boundaries Are Interpretable**:

1. **Perceptually Discrete**: Humans perceive boundaries as "edges" (sentence breaks, paragraph divisions)
2. **Mathematically Continuous**: Boundary measures capture field gradients (∂Q/∂x, ∇c)
3. **Computationally Local**: Evaluating γ_sem(i, i+1) requires only two adjacent nodes, not global integration

**Stokes Theorem as Interpretability Bridge**:

$$
\int_{\partial A} \omega = \int_A d\omega
$$

Left side (boundary integral): Perceptually discrete—walk along ∂A summing contributions

Right side (volume integral): Requires full interior knowledge—integration over int(A)

**Semantic Translation**:

- Superficial layer shows ∫_∂A (boundary discontinuities) → visually **scannable**
- Deep layer shows ∫_A ∇·τ (interior shear field) → requires **analytical engagement**

Both represent the same holistic measure state, but boundary projection is **interpretable** because it maps continuous fields onto discrete visual anchors (borders, edges, transitions).

### Revised Measure Group Hierarchy

| **Overlay Layer** | **Measure Group** | **Interpretability Mechanism** | **Physical Analog** |
| --- | --- | --- | --- |
| **Superficial (1)** | Boundary measures: γ_sem, τ_narr, ∂coherence | **Discrete visual anchors** (borders, bars) encode **continuous fields** (gradients, path integrals) | Surface phenomena: tension, wetting, contact angle |
| **Intermediate (2)** | Aggregate measures: c_chapter, w_ij | **Graph topology** makes coupling structure visible; node size/color encode continuous quality | Interface coupling: adhesion, coupling constants |
| **Deep (3)** | Violation measures: {Q_i < θ_i} | **Multi-attribute reasoning** via stacked visualizations; requires understanding of quality ensemble | Bulk properties: stress tensor, strain field |

**Key Architectural Insight**: Interpretability decreases as we move from boundary (Layer 1) to interior (Layer 4) not because deeper layers are "harder" but because they require **integration over structure** rather than **evaluation at interfaces**.

## Metric 1: Surface Tension (γ_sem)

### Physical Context: Shear vs Surface

**Shear Stress** (τ): Bulk interior phenomenon

$$
\tau = \mu \frac{\partial u}{\partial z}
$$

Requires:

- Velocity gradient **through entire volume** (3D field knowledge)
- Viscosity coefficient μ (material property)
- Boundary conditions on all surfaces
- **Interpretation**: Requires understanding of stress tensors, coordinate systems

**Surface Tension** (γ): Interface boundary phenomenon

$$
\gamma = \frac{\partial E}{\partial A}
$$

Requires:

- Only interface configuration (2D manifold embedded in 3D)
- Local energy balance (thermodynamic potential)
- **Interpretation**: Directly observable (soap bubble curvature, capillary rise measured with ruler)

### Semantic Translation: Full Shear vs Boundary Discontinuity

**Full Shear** (Deep Layer):

$$
\tau^{\text{vert}}_A = c_A - \mathbb{E}[c_{\text{children}} \mid \mathcal{F}_A]
$$

This captures **deviation of node composition from capacity-weighted average of descendants**.

Requires understanding:

- Filtration ℱ₀ ⊃ ℱ₁ ⊃ ... ⊃ ℱₙ (hierarchical σ-algebras)
- Conditional expectation (Radon-Nikodym theorem application)
- Capacity weighting (μ_w as reference measure)

**Interpretability barrier**: User must mentally integrate over all descendants and compute weighted average before seeing deviation.

**Surface Tension** (Superficial Layer):

$$
\gamma_{\text{sem}}(i, i+1) = \sum_{j=1}^{m} |c_i^{(j)} - c_{i+1}^{(j)}| \cdot w_j
$$

This captures **boundary discontinuity in tonal composition** between adjacent sentences.

Requires understanding:

- Two adjacent nodes exist (discrete structure: visually obvious in grid)
- Color-coded border thickness encodes magnitude (continuous field: perceptually immediate)

**Interpretability advantage**: User sees thick red border → "abrupt transition here" without any mathematical calculation.

### Why γ_sem Brokers Discrete-Continuous Gap

**Discrete Anchor**: Sentence boundary i | i+1 is a hard partition (perceptually discrete)

**Continuous Field**: Composition c varies smoothly in Δₘ₋₁ simplex (mathematically continuous)

**Bridge**: γ_sem evaluates continuous gradient ∇c at discrete boundary location

**Visualization Encoding**:

- **Position**: Horizontal line between rows i and i+1 (discrete grid coordinate)
- **Color**: Red/yellow/green gradient (continuous field mapped to perceptual scale)
- **Thickness**: Proportional to γ_sem (continuous magnitude → discrete line width)

The border is simultaneously:

- **Discrete** (you can point to it: "this specific boundary")
- **Continuous** (color smoothly interpolates, thickness varies smoothly)

This dual nature is exactly what's needed to make continuous measure γ_sem interpretable on discrete text structure.

### Implementation

```python
def compute_surface_tension(
    self,
    sentence_i: str,
    sentence_j: str,
    tone_weights: Optional[Dict[str, float]] = None
) -> float:
    """
    Compute L¹ compositional discontinuity between adjacent sentences.
    
    Physical interpretation: Energy required to smooth interface between i and i+1.
    
    Args:
        sentence_i: First sentence ID (discrete structural anchor)
        sentence_j: Adjacent sentence ID
        tone_weights: Optional weights {tone: w_j} for dimensional scaling
    
    Returns:
        γ_sem ∈ [0, 2] where:
        - 0 = perfect continuity (no interface energy)
        - 2 = maximum discontinuity (disjoint compositions)
    """
    c_i = self.export.compositions.get(sentence_i)
    c_j = self.export.compositions.get(sentence_j)
    
    if c_i is None or c_j is None:
        return 0.0
    
    # L¹ distance (choice motivated by dimensional reasoning:
    # γ_sem should have units of [tonal difference] matching physics)
    if tone_weights is None:
        gamma_sem = np.sum(np.abs(c_i - c_j))
    else:
        weights = np.array([tone_weights.get(tone, 1.0) 
                           for tone in sorted(tone_weights.keys())])
        gamma_sem = np.sum(weights * np.abs(c_i - c_j))
    
    return gamma_sem
```

## Metric 2: Narrative Tortuosity (τ_narr)

### Physical Context: Path Efficiency in Porous Media

**Tortuosity** measures diffusion path efficiency:

$$
\tau_{\text{tort}} = \frac{L_{\text{actual}}}{L_{\text{straight}}}
$$

**Physical Interpretation**:

- τ = 1: Straight channel (100% efficient)
- τ = 1.5: 50% longer path than ideal (wasted diffusion distance)
- Appears in effective transport: D_eff = D₀/(τ²φ) (Bruggeman equation)

**Why This Is Interpretable**:

- Dimensionless ratio (no units → immediate comparison)
- Path visualization is intuitive (humans navigate paths daily)
- Deviation from ideal (τ - 1) is "excess cost" → economic/efficiency intuition

### Semantic Translation: Text as Semantic Space Trajectory

**Narrative tortuosity** measures path efficiency through semantic space:

$$
\tau_{\text{narr}}(i, i+k) = \frac{\sum_{j=i}^{i+k-1} d(s_j, s_{j+1})}{d(s_i, s_{i+k})}
$$

**Discrete Elements**:

- Sentences {s_i, s_{i+1}, ..., s_{i+k}} form discrete path nodes
- Window [i, i+k] has discrete boundaries

**Continuous Field**:

- Distance function d(s_i, s_j) is continuous (varies smoothly with composition)
- Path integral ∑ d(s_j, s_{j+1}) is continuous (real-valued sum)

**Interpretability Bridge**:

- Users see **vertical bars** (discrete: you can count how many sentences have high τ)
- Bar color encodes τ_narr (continuous: green → yellow → red gradient)
- Bar position aligns with sentence rows (discrete anchor)

### Three Distance Metric Options

### Option A: Entity Transition Distance

$$
d_{\text{entity}}(s_i, s_j) = 1 - \frac{|E_i \cap E_j|}{|E_i \cup E_j|}
$$

**Discrete-Continuous Mediation**:

- Entity sets E_i, E_j are discrete (countable elements)
- Jaccard similarity is continuous (varies smoothly from 0 to 1)
- **Interpretability**: "How many entities change between sentences?" → visually countable in grid

### Option B: Compositional Distance (Recommended)

$$
d_{\text{comp}}(s_i, s_j) = ||c_i - c_j||_1 = \sum_{j=1}^{m} |c_i^{(j)} - c_j^{(j)}|
$$

**Discrete-Continuous Mediation**:

- Sentences i, j are discrete indices
- Composition c ∈ Δₘ₋₁ is continuous (simplex is convex, connected)
- L¹ distance is continuous but componentwise computable (sum of discrete differences)
- **Interpretability**: Connects to γ_sem (same metric, but path-integrated vs boundary-evaluated)

**Why This Works for Superficial Layer**:

- User doesn't need to understand Radon-Nikodym derivatives to see result
- Bar height encodes "how much tonal wandering" → physical intuition (elevation = effort)
- Color gradient (green/yellow/red) maps to efficiency (traffic light association)

### Option C: Lexical Cohesion Distance

$$
d_{\text{lex}}(s_i, s_j) = 1 - \cos(\text{tfidf}_i, \text{tfidf}_j)
$$

**Discrete-Continuous Mediation**:

- TF-IDF vectors are high-dimensional discrete (one dimension per vocabulary term)
- Cosine similarity is continuous (real-valued in [0,1])
- **Interpretability**: "How much vocabulary overlap?" → linguistic familiarity

### Recommended: Compositional Distance

**Rationale**: Connects boundary phenomenon (γ_sem) to path phenomenon (τ_narr) using same continuous field (c).

**Physical Analogy**: Like how electric field E and voltage potential φ are related:

- γ_sem ↔ E = -∇φ (local gradient, boundary)
- τ_narr ↔ ∫ E·ds (path integral, connects boundaries)

Same underlying field (tonal composition c), two complementary views optimized for different interpretability needs.

### Implementation

```python
def compute_narrative_tortuosity(
    self,
    sentence_range: List[str],
    window_size: int = 5,
    metric: str = 'compositional'
) -> Dict[str, float]:
    """
    Compute path efficiency through semantic space over sliding windows.
    
    Physical interpretation: τ_narr = (actual semantic path) / (ideal direct path)
    Dimensionless ratio enables cross-text comparison.
    
    Args:
        sentence_range: Ordered list of sentence IDs (discrete path nodes)
        window_size: Path length to measure (discrete: number of steps)
        metric: Distance function choice (affects continuous field definition)
    
    Returns:
        {sentence_id: τ_narr} where τ ≥ 1 (equality when path is straight)
    """
    tortuosity = {}
    
    for i in range(len(sentence_range) - window_size):
        window = sentence_range[i:i+window_size+1]
        
        # Actual path length: sum of discrete steps in continuous field
        path_length = sum(
            self._distance(window[j], window[j+1], metric)
            for j in range(window_size)
        )
        
        # Direct distance: continuous field evaluation at discrete endpoints
        direct_distance = self._distance(window[0], window[-1], metric)
        
        # Tortuosity: dimensionless ratio (interpretable as "% excess path")
        if direct_distance > 1e-6:
            tortuosity[window[0]] = path_length / direct_distance
        else:
            # Degenerate case: no semantic motion (stationary in field)
            tortuosity[window[0]] = 1.0 if path_length < 1e-6 else float('inf')
    
    return tortuosity

def _distance(self, sent_i: str, sent_j: str, metric: str) -> float:
    """
    Compute distance in semantic space between discrete sentence nodes.
    
    Returns continuous real value encoding field variation.
    """
    if metric == 'entity':
        entities_i = self._get_entities(sent_i)
        entities_j = self._get_entities(sent_j)
        intersection = len(entities_i & entities_j)
        union = len(entities_i | entities_j)
        return 1 - (intersection / union if union > 0 else 0)
    
    elif metric == 'compositional':
        c_i = self.export.compositions.get(sent_i)
        c_j = self.export.compositions.get(sent_j)
        if c_i is not None and c_j is not None:
            return np.sum(np.abs(c_i - c_j))
        return 0.0
    
    elif metric == 'lexical':
        vec_i = self._get_tfidf_vector(sent_i)
        vec_j = self._get_tfidf_vector(sent_j)
        norm_i = np.linalg.norm(vec_i)
        norm_j = np.linalg.norm(vec_j)
        if norm_i > 0 and norm_j > 0:
            return 1 - [np.dot](http://np.dot)(vec_i, vec_j) / (norm_i * norm_j)
        return 0.0
    
    else:
        raise ValueError(f"Unknown metric: {metric}")
```

## Relationship to Deeper Layers via Stokes Theorem

### The Interpretability Hierarchy

**Superficial Layer** (∂A measures):

$$
\oint_{\partial A} \gamma_{\text{sem}} \, ds = \text{boundary discontinuity}
$$

- **Discrete anchor**: Walk along boundaries ∂A (sentence borders visible in grid)
- **Continuous field**: γ_sem(s) varies along path s
- **Interpretability**: Scannable—eye can trace colored borders

**Deep Layer** (int(A) measures):

$$
\int_A \nabla \cdot \tau^{\text{vert}} \, dV = \text{interior shear divergence}
$$

- **Continuous throughout**: Requires integration over all of A
- **No discrete anchor**: Interior is homogeneous (no natural visual partition)
- **Interpretability**: Requires analytical engagement—must understand divergence theorem

**Stokes Bridge**:

$$
\oint_{\partial A} \gamma_{\text{sem}} \, ds = \int_A \nabla \cdot \tau^{\text{vert}} \, dA
$$

Left side (superficial) = Right side (deep) **mathematically**, but interpretability differs:

- **Superficial**: Discrete visual scan (boundary walk)
- **Deep**: Continuous analytical integration (volume calculation)

### Cognitive Filtration as Projection

Define **cognitive σ-algebra** 𝒞_superficial ⊂ 𝒞_deep:

$$
\mathcal{C}_{\text{superficial}} = \sigma(\{\text{boundary discontinuities at sentence transitions}\})
$$

$$
\mathcal{C}_{\text{deep}} = \sigma(\{\text{all interior shear components across hierarchy}\})
$$

**Conditional Expectation as Interpretability Operator**:

$$
\gamma_{\text{sem}} = \mathbb{E}[\tau^{\text{vert}} \mid \mathcal{C}_{\text{superficial}}]
$$

This says: "Surface tension is the projection of volumetric shear onto the boundary σ-algebra."

**Why This Increases Interpretability**:

- 𝒞_superficial contains only boundary events (finite, countable)
- 𝒞_deep contains all interior events (uncountable, continuous)
- Conditioning on 𝒞_superficial **discretizes** the continuous shear field into perceptually manageable boundary discontinuities

**Physics Analogy**: Like how:

- **Gauss's Law** (surface integral) = **Poisson's Equation** (volume integral)
- Surface formulation is interpretable (count flux through boundary)
- Volume formulation requires solving PDE (continuous field everywhere)

Same physics, different **computational cognitive load**.

## Design Rationale: Why Superficial ≠ Shallow

### Topological Precision

**Boundary ∂A is not "less important" than Interior int(A)**:

- Both are well-defined mathematical objects
- Stokes theorem proves their equivalence (boundary data determines interior via PDE)
- Gauss-Bonnet theorem: Total curvature (global, interior) = Euler characteristic (topological, combinatorial)

**In Differential Geometry**:

- de Rham cohomology: H^n(M) classifies holes via closed/exact forms
- Poincaré dual: ∂M boundary class ↔ [M] fundamental class (isomorphism)

**Superficial is Not a Simplification**—it's a **projection** that preserves essential structure while increasing interpretability.

### Visualization as Projection, Not Approximation

**Key Distinction**:

**Bad Approach** (approximation):

- Compute full measure state (Ω, ℱ, μ)
- **Approximate** with simpler model (e.g., finite-dimensional embedding, lossy compression)
- Show approximation to user

**Our Approach** (projection):

- Compute full measure state (Ω, ℱ, μ)
- **Project** onto boundary σ-algebra 𝒞_superficial (lossless—can recover interior via Stokes if needed)
- Show projection to user

**Why Projection Preserves Rigor**:

By Stokes theorem, if we know γ_sem on all boundaries, we can reconstruct interior shear:

$$
\tau^{\text{vert}}(x) = \int_{\text{path to } x} \nabla \gamma_{\text{sem}} \, ds
$$

So superficial layer contains **complete information** about interior, just in boundary-encoded form.

**Interpretability Advantage**: Boundary encoding is perceptually discrete (countable borders) while interior encoding is perceptually continuous (uncountable interior points).

## Summary: Superficial Layer as Interpretability Engine

**The Discrete-Continuous Dilemma**: Text is discrete, linguistic quality is continuous—visualization bridges this via simultaneous representation.

**Why Boundary Measures**: ∂A naturally mediates discrete structure (sentence boundaries) and continuous fields (compositional gradients).

**Physics-Based Interpretability**: Surface tension, tortuosity, and other boundary phenomena invoke physical intuition humans evolved to understand.

**Not Shallow, but Projected**: Superficial layer is not a simplification—it's a projection of full measure-theoretic state onto boundary σ-algebra, preserving complete information (via Stokes theorem) while increasing perceptual interpretability.

**Layered Architecture Advantage**: Users can remain at boundary layer (superficial) for interpretability or drill down to interior analysis (deep layer) for analytical depth—both views access the same holistic measure state.
