Three-Axis Actuation-Space Smoothness: the Command Vector q = [δ, b, a]⊤ as a Curve

Steering, brake, and acceleration form one trajectory z(t) = D−1q(t) through normalized actuation space. Smoothness decomposes as regularity (z ∈ C r) + intensity (small ‖z‖) + coordination (low curvature κq). Drag the 3-D view; hover any chart.

Units differ, so normalize first:  z(t) = D−1q(t),  D = diag(δref, bref, aref)  — here 30°, 1, 6 m/s².
Coupling caveat: b and a are not independent controls — a = f(b, drive torque, v, grade, …); this simulation uses a = adrive − ab,maxb with ab,max = 7 m/s². [δ, b, a] is therefore a joint actuator–response coordinate, not three independent commands.
BThe smoothness triadwhat “smooth” means, mathematically
1 · Regularity — derivative continuity
z ∈ C r :  C 0 no jumps in δ, b, a · C 1 continuous δ, b, j · C 2 continuous δ, b, j
Working requirement: z ∈ C 1 with z, z bounded; C 2 preferred when actuator dynamics and passenger comfort matter.
2 · Intensity — magnitude of combined change
νq(t) = √(z⊤W z) ·  Jsmooth = ∫₀T (z⊤W₁z + z⊤W₂z) dt
The speed of travel through actuation space, and the trajectory cost penalizing rapid actuation and rapid changes of actuation rate (here W = W₁ = W₂ = I).
3 · Coordination — how the mixture of channels turns
κq = ‖z × z‖ / ‖z‖³ ·  τq = det(z, z, z(3)) / ‖z × z‖²
Low κq: the steering–brake–acceleration mixture rotates gradually. High κq: abrupt switching — hard braking handed straight into sharp steering. Torsion τq captures three-way re-coordination. κq is geometric; traversed at speed, the felt re-aiming is the normal acceleration κqνq².
Physical mapping (kinematic bicycle, ay ≈ (v²/L) tan δ):  jy ≈ (2va/L) tan δ + (v²/L) sec²δ · δ — lateral jerk couples a, δ, and δ: even with j = 0, a fast steering rate produces large lateral jerk.

Smoothness = derivative continuity (regularity) + small derivative norms (intensity) + low actuation-space curvature (coordination).
j = 0 freezes only the acceleration coordinate — steering and brake may still change violently; full constancy is q = 0 ⇔ δ = b = j = 0. And because brake demand shapes realized acceleration, q = [δ, b, a]⊤ is a joint actuator–response state: lateral, longitudinal, and rotational smoothness must be judged together.
