# Notion Block URL Extraction & Unfurling Solution

## The Problem

The Notion API exposes block IDs but not block-level URLs when rendering content as markdown. While you can see URLs for pages and databases, individual blocks (headings, tables, paragraphs, etc.) don’t have visible URLs in the markdown output.

## The Solution

This n8n-based solution:

1. **Extracts block IDs** from the Notion API
2. **Constructs block URLs** using the pattern: `https://www.notion.so/{page_id}#{block_id_without_hyphens}`
3. **Indexes all blocks** in a PostgreSQL database
4. **Enables unfurling** of block-level URLs

## How Notion Block URLs Work

Every Notion block has a unique ID like: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`

To create a direct URL to a block:
1. Get the page ID: `123abc`
2. Remove hyphens from block ID: `a1b2c3d4e5f67890abcdef1234567890`
3. Construct URL: `https://www.notion.so/123abc#a1b2c3d4e5f67890abcdef1234567890`

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│  Indexing Flow (Runs every 6 hours)                         │
├─────────────────────────────────────────────────────────────┤
│  Schedule Trigger                                            │
│       ↓                                                      │
│  Get All Pages (from Notion database)                       │
│       ↓                                                      │
│  For Each Page: Get All Blocks                              │
│       ↓                                                      │
│  Process Blocks (extract IDs, construct URLs)               │
│       ↓                                                      │
│  Store in PostgreSQL                                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  Unfurling Flow (Triggered by webhook)                      │
├─────────────────────────────────────────────────────────────┤
│  Webhook: Receive URL                                        │
│       ↓                                                      │
│  Extract Block ID from URL anchor (#...)                    │
│       ↓                                                      │
│  Query PostgreSQL for block metadata                        │
│       ↓                                                      │
│  Format unfurl response                                      │
│       ↓                                                      │
│  Return block card with title, description, URL             │
└─────────────────────────────────────────────────────────────┘
```

## Setup Instructions

### 1. Database Setup

Run the SQL schema to create the necessary tables:

```bash
psql -U your_username -d your_database -f notion-blocks-schema.sql
```

Or manually:

```sql
CREATE TABLE notion_blocks (
    block_id VARCHAR(36) PRIMARY KEY,
    block_id_no_hyphens VARCHAR(32) NOT NULL UNIQUE,
    block_url TEXT NOT NULL,
    page_id VARCHAR(36) NOT NULL,
    page_title TEXT NOT NULL,
    page_url TEXT NOT NULL,
    block_type VARCHAR(50) NOT NULL,
    block_content TEXT,
    has_children BOOLEAN DEFAULT FALSE,
    created_time TIMESTAMP,
    last_edited_time TIMESTAMP,
    indexed_at TIMESTAMP NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_block_id_no_hyphens ON notion_blocks(block_id_no_hyphens);
CREATE INDEX idx_page_id ON notion_blocks(page_id);
```

### 2. Notion API Setup

1. Go to https://www.notion.so/my-integrations
2. Create a new integration
3. Get your API key (starts with `secret_...`)
4. Share your Notion pages/databases with the integration

### 3. n8n Configuration

### Import the workflows:

1. **Basic Extractor**: `notion-block-extractor.json`
    - Simple webhook-based extractor
    - Returns all blocks for a given page URL
2. **Full Indexer + Unfurl**: `notion-block-indexer-unfurl.json`
    - Scheduled indexing of all Notion content
    - Webhook endpoint for unfurling block URLs

### Configure credentials:

1. **Notion API Credential**:
    - Add your Notion API key
2. **PostgreSQL Credential**:
    - Host, port, database name
    - Username and password

### Set environment variables:

In n8n, set:

```
NOTION_PAGES_DATABASE_ID=your_database_id_here
```

To find your database ID:
- Open your Notion database
- Copy the URL: `https://notion.so/workspace/DATABASE_ID?v=...`
- The DATABASE_ID is the part before `?v=`

### 4. Activate the Workflows

1. Import both JSON files into n8n
2. Update the credential references
3. Test the webhook endpoints
4. Activate the scheduled indexer

## Usage Examples

### Example 1: Extract blocks from a single page

**Request:**

```bash
curl -X POST http://your-n8n-url/webhook/notion-blocks \  -H "Content-Type: application/json" \  -d '{"url": "https://www.notion.so/My-Page-123abc"}'
```

**Response:**

```json
{  "blocks": [    {      "blockId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",      "blockUrl": "https://www.notion.so/123abc#a1b2c3d4e5f67890abcdef1234567890",      "type": "heading_2",      "content": "Introduction",      "hasChildren": false    },    {      "blockId": "b2c3d4e5-f6a7-8901-bcde-f12345678901",      "blockUrl": "https://www.notion.so/123abc#b2c3d4e5f6a78901bcdef12345678901",      "type": "paragraph",      "content": "This is a paragraph with some text...",      "hasChildren": false    }  ]}
```

### Example 2: Unfurl a block URL

**Request:**

```bash
curl -X POST http://your-n8n-url/webhook/notion-block-unfurl \  -H "Content-Type: application/json" \  -d '{"url": "https://www.notion.so/123abc#a1b2c3d4e5f67890abcdef1234567890"}'
```

**Response:**

```json
{  "type": "block_card",  "block_card": {    "title": {      "type": "text",      "text": "My Page - Heading 2"    },    "description": {      "type": "text",      "text": "Heading 2 | Introduction"    },    "url": "https://www.notion.so/123abc#a1b2c3d4e5f67890abcdef1234567890"  }}
```

### Example 3: Search indexed blocks

```sql
-- Search for blocks containing "OAuth"SELECT * FROM search_notion_blocks('OAuth');
-- Get all heading blocksSELECT block_url, page_title, block_content
FROM notion_blocks
WHERE block_type LIKE 'heading_%'ORDER BY last_edited_time DESC;
-- Get all blocks from a specific pageSELECT block_url, block_type, block_content
FROM notion_blocks
WHERE page_id = 'your-page-id-here'ORDER BY created_time;
```

## Advanced Features

### Nested Blocks

The workflow marks blocks that have children with `has_children: true`. To get nested blocks:

1. Query blocks with `has_children = true`
2. Make additional API calls to fetch children
3. Store with parent-child relationships

### Full-Text Search

The PostgreSQL schema includes full-text search capabilities:

```sql
SELECT * FROM search_notion_blocks('your search term')
LIMIT 10;
```

### Real-Time Updates

To get real-time updates instead of scheduled indexing:

1. Set up Notion webhooks (when available)
2. Or reduce schedule interval to 1 hour
3. Or trigger indexing via API when pages are edited

## Limitations & Considerations

1. **Rate Limits**: Notion API has rate limits (3 requests/second). The workflow includes batching.
2. **Storage**: Each block is ~1KB. 10,000 blocks = ~10MB of database storage.
3. **Sync Frequency**: Default is 6 hours. Adjust based on your needs.
4. **Large Pages**: Pages with 1000+ blocks may timeout. Consider pagination.
5. **Private Content**: Only indexes pages shared with your integration.

## Troubleshooting

### Issue: No blocks returned

**Solution**: Ensure the Notion integration has access to the page:
1. Open the page in Notion
2. Click Share
3. Invite your integration

### Issue: Block URLs don’t work

**Solution**: Verify the URL format:
- Correct: `https://www.notion.so/123abc#a1b2c3d4e5f67890abcdef1234567890`
- Incorrect: `https://www.notion.so/123abc#a1b2c3d4-e5f6-7890-abcd-ef1234567890` (includes hyphens)

### Issue: Database errors

**Solution**: Check PostgreSQL connection and ensure the schema is created.
