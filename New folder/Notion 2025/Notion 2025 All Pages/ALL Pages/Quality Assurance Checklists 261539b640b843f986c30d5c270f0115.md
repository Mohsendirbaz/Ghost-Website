# Quality Assurance Checklists

Practical, actionable checklists for systematic text quality review.

---

## Pre-Flight Checks

### Document-Level

- [ ]  **Clear thesis or main argument established**
    - Can you state it in one sentence?
    - Is it present in introduction?
    - Does it reappear in conclusion?
- [ ]  **All sections directly support the main theme**
    - Each section advances the argument
    - No tangential content
    - Clear section purposes
- [ ]  **No off-topic digressions**
    - Every paragraph relevant
    - Interesting but irrelevant content removed
    - "Kill your darlings" applied
- [ ]  **Logical section ordering**
    - Each section builds on previous
    - Prerequisites come first
    - Natural progression
    - Can defend ordering rationale
- [ ]  **Appropriate scope**
    - Not too broad (surface coverage)
    - Not too narrow (excessive detail)
    - Audience expectations met

---

## Paragraph-Level Checks

### Structure

- [ ]  **Each paragraph has clear topic sentence**
    - Usually first sentence
    - States main point
    - Reader knows what paragraph is about
- [ ]  **Internal coherence within paragraphs**
    - All sentences relate to topic
    - Logical sentence ordering
    - Unity maintained
- [ ]  **Smooth transitions between paragraphs**
    - Transitional phrases used
    - Logical connections explicit
    - No jarring jumps
    - Reader anticipates next topic
- [ ]  **Adequate development**
    - Not too thin (underdeveloped)
    - Not too dense (overloaded)
    - ~5-8 sentences typically
    - One main idea per paragraph

### Content

- [ ]  **Each paragraph advances the argument**
    - Not purely descriptive (unless appropriate)
    - Analysis present
    - Connection to thesis clear
- [ ]  **Evidence provided where needed**
    - Claims supported
    - Examples given
    - Data/citations included
- [ ]  **Balanced paragraph lengths**
    - Vary naturally
    - No single-sentence paragraphs (usually)
    - No half-page blocks

## Sentence-Level Checks

### Grammar & Structure

- [ ]  **Clear subject-verb-object structure**
    - Reader identifies "who does what"
    - Active voice predominates (80%+)
    - Subjects aren't buried
- [ ]  **Varied sentence length and complexity**
    - Mix of short and long
    - Simple + compound + complex
    - Rhythm established
    - No monotonous patterns
- [ ]  **No run-on sentences or fragments**
    - Sentence boundaries clear
    - Independent clauses properly joined
    - Fragments used only deliberately (rare)
- [ ]  **Appropriate use of subordination**
    - Main idea in main clause
    - Supporting info in subordinate
    - Logical relationships clear
    - Not over-subordinated
- [ ]  **Parallel structure where appropriate**
    - Lists use consistent form
    - Comparisons balanced
    - "Not only X but also Y"

### Clarity

- [ ]  **No ambiguous pronouns**
    - Every "it," "this," "that" has clear referent
    - Within same sentence or previous
    - No reader confusion
- [ ]  **Concrete subjects and verbs**
    - Avoid nominalizations ("The implementation of the plan" → "We implemented the plan")
    - Strong verbs (not just "is," "has," "does")
    - Specific nouns
- [ ]  **Appropriate specificity**
    - Not too vague ("things," "stuff")
    - Not unnecessarily technical
    - Right level for audience

## Cohesion Device Checks

### Reference & Repetition

- [ ]  **Appropriate pronoun references**
    - Clear antecedents
    - No ambiguity
    - Gender/number agreement
    - Distance not too great
- [ ]  **Effective use of transition words**
    - Logical connectors present:
        - Addition: "furthermore," "moreover"
        - Contrast: "however," "nevertheless"
        - Cause: "therefore," "thus," "consequently"
        - Example: "for instance," "specifically"
    - Not overused
    - Appropriate to relationship
- [ ]  **Repetition of key terms (not excessive)**
    - Important concepts repeated
    - Creates coherence
    - But not monotonous
    - Strategic emphasis
- [ ]  **Synonym variation where appropriate**
    - Elegant variation for style
    - BUT: Technical terms stay consistent
    - Don't vary for its own sake

### Cohesive Devices

- [ ]  **Effective use of substitution**
    - "This approach," "Such methods"
    - "The former," "The latter"
    - Ellipsis where clear
- [ ]  **Lexical chains maintained**
    - Related words create continuity
    - Semantic field consistency
    - Example: "teacher" → "educator" → "instruction"
- [ ]  **Parallel tracking**
    - If comparing A and B, maintain structure
    - "A has X; B has Y"
    - "First A, then B, finally C"

## Argumentation Quality Checks

### Toulmin Structure

- [ ]  **Claims are clearly stated**
    - Not implied or assumed
    - Explicit assertion
    - Identifiable as claims
- [ ]  **Evidence supports each claim**
    - Data, examples, expert opinion
    - Sufficient quantity
    - Relevant to claim
    - Source credible
- [ ]  **Warrants connect evidence to claims**
    - Explicit reasoning provided
    - "Because X, therefore Y"
    - Assumptions stated
    - Logical link clear
- [ ]  **Qualifiers used appropriately**
    - "Likely," "probably," "in most cases"
    - Avoids overgeneralization
    - Acknowledges uncertainty
    - Maintains credibility
- [ ]  **Counterarguments acknowledged**
    - Alternative views presented
    - Fairly represented
    - Rebutted effectively
    - Shows comprehensive thinking
- [ ]  **Rebuttals provided**
    - Responses to counter-arguments
    - Limitations acknowledged
    - Conditions specified

### Logical Consistency

- [ ]  **No internal contradictions**
    - Statements align throughout
    - Check intro vs. conclusion
    - Verify data consistency
- [ ]  **Logical fallacies avoided**
    - No ad hominem
    - No straw man
    - No false dichotomy
    - No hasty generalization
    - No circular reasoning
    - No post hoc ergo propter hoc
- [ ]  **Premises support conclusion**
    - Deductive arguments valid
    - Inductive arguments strong
    - No logical leaps

## Final Polish Checks

### Sentence-Level Polish

- [ ]  **Remove filler words**
    - "Very," "really," "quite"
    - "In order to" → "to"
    - "Due to the fact that" → "because"
- [ ]  **Eliminate redundancies**
    - "Past history" → "history"
    - "Future plans" → "plans"
    - "End result" → "result"
- [ ]  **Check for wordiness**
    - Can you say it in fewer words?
    - Is every word pulling its weight?
    - Concision without losing meaning
- [ ]  **Active voice where possible**
    - "We conducted the experiment" > "The experiment was conducted"
    - Exception: When actor unknown or irrelevant

### Word Choice

- [ ]  **Precise vocabulary**
    - "Said" vs. "asserted," "claimed," "argued"
    - Choose most accurate term
    - Avoid vague verbs ("do," "make," "get")
- [ ]  **Appropriate register**
    - Formal vs. informal consistent
    - Contractions appropriate?
    - Slang appropriate?
- [ ]  **Avoid clichés**
    - "At the end of the day"
    - "Think outside the box"
    - "Low-hanging fruit"
    - Use fresh language

### Punctuation & Mechanics

- [ ]  **Comma usage correct**
    - Serial comma consistent
    - No comma splices
    - Appropriate for clauses
- [ ]  **Semicolons used correctly**
    - Join independent clauses
    - Separate complex list items
- [ ]  **Apostrophes correct**
    - Possessives vs. plurals
    - Its vs. it's
    - Contractions appropriate
- [ ]  **Dashes used effectively**
    - Em dashes for interruption
    - En dashes for ranges
    - Not overused
- [ ]  **Capitalization consistent**
    - Title case for headings
    - Proper nouns
    - Terms of art

## Coherence-Specific Deep Checks

### Structural Coherence

- [ ]  **Outline makes logical sense**
    - Print outline, review separately
    - Each point follows from previous
    - Parallel structure in headings
- [ ]  **Section lengths proportional**
    - Major points get more space
    - Minor points appropriately brief
    - No single-paragraph sections
- [ ]  **Headings accurately reflect content**
    - Not misleading
    - Appropriate specificity
    - Consistent style

### Reference Coherence

- [ ]  **Cross-references all valid**
    - "As discussed in Chapter 3"
    - "See Figure 2" (Figure 2 exists)
    - "The aforementioned approach"
- [ ]  **Forward references justified**
    - "As we will see" sparingly
    - Don't rely on future content
    - Setup-payoff structure deliberate
- [ ]  **Capacity-weighted connections strong**
    - Major chapters well-integrated
    - Important entities referenced frequently
    - Hierarchical coherence maintained

### Semantic Coherence

- [ ]  **Topic consistency within sections**
    - Run topic model, check clusters
    - No sudden topic shifts
    - Thematic unity
- [ ]  **Lexical cohesion maintained**
    - Related words used together
    - Semantic fields consistent
    - Concept chains unbroken
- [ ]  **Tone consistent**
    - Formal throughout, or informal
    - Emotional tone appropriate
    - No jarring shifts

## Automated Check Integration

### Run These Tools

**Grammar & Style**:

```bash
# LanguageTool
languagetool-commandline --language en-US text.txt

# Proselint
proselint text.txt
```

**Coherence Metrics**:

```python
# Capacity-weighted Jaccard
ref_score = compute_reference_coherence(chapter_refs)

# Entity grid
entity_score = compute_entity_coherence(text)

# Semantic similarity
semantic_score = compute_semantic_coherence(paragraphs)

# Generate report
print(f"Reference: {ref_score:.2f}")
print(f"Entity: {entity_score:.2f}")
print(f"Semantic: {semantic_score:.2f}")
```

**Readability**:

```python
from textstat import textstat

flesch = textstat.flesch_reading_ease(text)
gunning = textstat.gunning_fog(text)
smog = textstat.smog_index(text)

print(f"Flesch: {flesch} (aim for 50-60 for academic)")
print(f"Gunning Fog: {gunning} (aim for 12-15 for technical)")
```

### Flag These Issues

**Automated red flags**:

- Coherence score < 0.4
- Entity discontinuity detected
- Missing discourse markers (< 1 per 100 words)
- Readability inappropriate for genre
- Sentence length variance too low (monotonous)
- Passive voice > 20%
- Paragraph length outliers

## Review Sequence

### First Pass: Structural

1. Read headings only
2. Check outline logic
3. Verify section purposes
4. Review introduction-conclusion alignment

### Second Pass: Paragraph-Level

1. Check each topic sentence
2. Verify paragraph unity
3. Test transitions
4. Assess development

### Third Pass: Sentence-Level

1. Read aloud (catches rhythm issues)
2. Check every pronoun reference
3. Verify subject-verb clarity
4. Polish word choice

### Fourth Pass: Line Edit

1. Grammar and punctuation
2. Spelling
3. Consistency (names, terms, formatting)
4. Remove typos

### Fifth Pass: Automated

1. Run coherence metrics
2. Check readability
3. Grammar tools
4. Address flagged issues

### Final Pass: Fresh Eyes

1. Wait 24-48 hours
2. Read straight through
3. Note confusion points
4. Check against checklist

## Troubleshooting Common Issues

### "Text feels disjointed"

**Diagnosis**: Low coherence scores

**Solutions**:

- Add transition sentences
- Strengthen paragraph connections
- Review section ordering
- Check entity continuity
- Increase discourse markers

### "Argument feels weak"

**Diagnosis**: Toulmin structure incomplete

**Solutions**:

- Identify all claims
- Add evidence for each
- Make warrants explicit
- Address counter-arguments
- Strengthen conclusion

### "Writing feels choppy"

**Diagnosis**: Low sentence variety

**Solutions**:

- Vary sentence length
- Mix simple and complex
- Use more subordination
- Combine short sentences
- Add transitional phrases

### "Hard to follow"

**Diagnosis**: Multiple possible causes

**Solutions**:

- Check pronoun clarity
- Add more signposting
- Break up long paragraphs
- Review paragraph topic sentences
- Simplify complex sentences

## Quality Thresholds

### Minimum Standards (Before Publication)

- Reference coherence: ≥ 0.60
- Entity coherence: ≥ 0.55
- Semantic coherence: ≥ 0.50
- Grammar errors: < 5 per 1000 words
- Flesch Reading Ease: 30-60 (academic/technical)
- Passive voice: < 20%
- Avg paragraph length: 5-8 sentences
- Transition marker density: ≥ 1 per 100 words

### Excellence Standards (99th Percentile)

- Reference coherence: ≥ 0.80
- Entity coherence: ≥ 0.75
- Semantic coherence: ≥ 0.70
- Grammar errors: < 2 per 1000 words
- All Toulmin elements present (argumentative)
- Strong narrative arc (fiction)
- Zero internal contradictions
- Professional polish throughout
